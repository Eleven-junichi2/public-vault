dereference operator。indirection operator。間接参照演算子とも。
`*` を用いて、[[ポインタ（C++）]]が指しているオブジェクトを参照する演算子。
結果は左辺値になるため、値の読み取りにも書き換えにも使える。

```cpp
#include <iostream>

int main()
{
    int x{ 5 };
    int* ptr{ &x };

    std::cout << *ptr << '\n';
    *ptr = 10;
    std::cout << x << '\n';
}
```
