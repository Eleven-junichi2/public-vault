## キーボードショートカット

- `Command + P`
	- コマンドパレットを開く
- `Ctrl + @`
	- ターミナルを開く・フォーカス
	- `Ctrl + shift + @`
		- ターミナルを開閉
- macOS:`Ctrl + 数字` Windows:`Alt + 数字`
	- エディタにフォーカス
	- 0で最右タブを選択
	- ~9で左から順のタブを選択
- macOS:`Shift + Command + e` Windows:`Ctrl + Shift + e`
	- エクスプローラーとエディタ間フォーカス切り替え
- `Option + Shift + A`
	- 複数行コメント
- 自作ショートカット
	- エクスプローラーにフォーカス中
		- `Command + n`
			- 新規ファイル作成
		- `Shift + Command + n`
			- 新規フォルダ作成
	- Vim拡張機能
		- `Ctrl + Shift + v`
			- Vim: Toggle Vim Mode
