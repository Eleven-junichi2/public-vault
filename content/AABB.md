Axis-Aligned Bounding Box. 軸平行境界ボックス。
各軸に並行な辺で構成する長方形による[[境界ボックス]]。

## ボックスと点の衝突判定

ボックスの左上隅の座標を$(x,y)$とし、幅を$w$、高さを$h$とする。このとき、ボックスの右端は$x+w$、下端は$y+h$となる。
点の座標を$(px,py)$とする。

衝突判定: $(x \le px \le x + w) \land (y \le py \le y+h)$
- 点がボックスと衝突している条件は、点の x 座標がボックスの左右の範囲にあり、かつ、点の y 座標がボックスの上下の範囲にあることである

## ボックス同士の衝突判定

###  左上隅の座標で位置をとるボックス

この場合、衝突判定はできるが重なりの程度を知ることが難しい。

#### 素直な方法

ボックスの各隅（４つの点）に対して、[[#ボックスと点の衝突判定]]を行う。
$4 \times 4=16$回のチェックが必要。

#### 水平方向・垂直方向の重なり

それぞれのボックスの上（左）端が一方のボックスの下（右）端より高いか（すなわち両方のボックスと交差する水平（垂直）線を引けるかどうかと言い換えられる）で、各軸方向の重なりを判定できる。どちらも重なっていれば、ボックス同士が交差するすなわち衝突していると言える

一方のボックスの左上隅の座標を$(x_1,y_1)$、幅を$w_1$、高さを$h_1$とする。
もう一方のボックスの左上隅の座標を$(x_2,y_2)$、幅を$w_2$、高さを$h_2$とする。

水平方向の衝突判定: $(y_1 \le y_2 + h_2) \land (y_2 \le y_1 + h_1)$
垂直方向の衝突判定: $(x_1 \le x_2 + w_2) \land (x_2 \le x_1 + w_1)$

[[#素直な方法]]と比べて、チェックする条件を減らすことができた。

### 中心の座標で位置をとるボックス

一方のボックスの中心座標を$(x_1,y_1)$、幅を$w_1$、高さを$h_1$とする。
もう一方のボックスの中心座標をを$(x_2,y_2)$、幅を$w_2$、高さを$h_2$とする。
このとき、二つのボックスの
- 水平方向の距離は$d_x=|x_2-x_1|$
- 垂直方向の距離は$d_y=|y_2-y_1|$
となる。

すると、
- 水平方向の重なりの程度は$o_x=(w_1 / 2) + (w_2 / 2) - d_x$
- 垂直方向の重なりの程度は$o_y=(h_1 / 2) + (h_2 / 2) - d_y$
と知ることができる。

すなわち、

水平方向で重なって**いない**とき：$(w_1 / 2) + (w_2 / 2) < d_x \iff o_x< 0$
水平方向で重なって**いる**とき：$d_x \leq (w_1 / 2) + (w_2 / 2) \iff 0 \leq o_x$

垂直方向で重なって**いない**とき：$(h_1 / 2) + (h_2 / 2) < d_y \iff o_y < 0$
垂直方向で重なって**いる**とき：$d_y \leq (h_1 / 2) + (h_2 / 2) \iff 0 \leq o_y$

のように判定できる。
