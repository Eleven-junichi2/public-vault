`consteval`で宣言された、常に[[コンパイル時評価]]される[[関数（C++）]]。
使用されたときにコンパイル時評価できない場合はエラーになる。
[[constexpr関数]]がコンパイル時にも実行時にも評価されうるのに対し、即時関数はコンパイル時評価を必ず要求する。

## 例

```cpp
consteval int add(int x, int y) {
    return x + y;
}

constexpr int a = add(10, 10); // ok
int b = 200;
int c = add(b, 1); // b は実行時の値なのでエラー
```
