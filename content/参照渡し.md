pass by reference。
関数の引数を参照型にして、呼び出し元の[[オブジェクト（C++）]]を直接参照させる渡し方。
[[値渡し]]のようにコピーを作らないため、コピーコストを避けたいときに用いられる。
非 `const` 参照を使うと、関数内での変更は呼び出し元にも反映される。

```cpp
#include <iostream>
#include <string>

void printValue(std::string& y)
{
    std::cout << y << '\n';
}

int main()
{
    std::string x { "Hello, world!" };

    printValue(x);
}
```
